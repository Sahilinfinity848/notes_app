
# Flutter Notes App

A simple Notes application developed using Flutter and Dart.

## Features

- Add new notes
- Edit existing notes
- Delete notes
- Search notes by title
- Save notes using SharedPreferences
- Light and Dark themes
- Display notes with dates

## Technologies Used

- Flutter
- Dart
- SharedPreferences
- Android Studio
- Visual Studio Code

## Project Structure

- models
- screens
- services
- widgets

## How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Run:

```bash
flutter pub get
flutter run
```
